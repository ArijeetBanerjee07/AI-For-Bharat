Combined Workflow: Validate + Submit in Parallel\n\nValidate documents AND submit to portals at the same time:\n\n```python\nimport asyncio\nfrom backend.submission_agent import (\n    validate_documents_batch,\n    submit_to_multiple_portals\n)\n\nasync def full_application_workflow():\n    documents = {\n        \"aadhar\": \"/path/to/aadhaar.pdf\",\n        \"income\": \"/path/to/income.pdf\",\n        \"photo\": \"/path/to/photo.jpg\"\n    }\n    \n    user_data = {\n        \"fullname\": \"Raj Kumar\",\n        \"dob\": \"1990-01-15\",\n        \"aadhar\": \"123456789012\",\n        \"mobile\": \"9876543210\",\n        \"email\": \"raj@example.com\",\n        \"address\": \"Village House\",\n        \"state\": \"delhi\",\n        \"district\": \"Central\",\n        \"city\": \"Delhi\",\n        \"pincode\": \"110001\"\n    }\n    \n    file_paths = {\n        \"aadhar\": documents[\"aadhar\"],\n        \"income\": documents[\"income\"],\n        \"photo\": documents[\"photo\"]\n    }\n    \n    portals = [\n        \"https://pmay-gramin.gov\",\n        \"https://pmjdy.gov\"\n    ]\n    \n    # Start validation and submission tasks in parallel\n    print(\"🚀 Starting parallel validation and submission...\")\n    \n    validation_task = validate_documents_batch(documents)\n    submission_task = submit_to_multiple_portals(user_data, file_paths, portals)\n    \n    # Wait for both to complete\n    validations, submissions = await asyncio.gather(\n        validation_task,\n        submission_task\n    )\n    \n    print(f\"\\n✅ Validation Results:\")\n    for i, (doc_type, result) in enumerate(zip(documents.keys(), validations), 1):\n        print(f\"   {i}. {doc_type}: {result['is_valid']} - {result['extracted_id']}\")\n    \n    print(f\"\\n✅ Submission Results:\")\n    for i, submission in enumerate(submissions['submissions'], 1):\n        print(f\"   {i}. Portal {i}: {submission['ref_number']}\")\n    \n    return {\n        \"validations\": validations,\n        \"submissions\": submissions\n    }\n\n# Run it\nresults = asyncio.run(full_application_workflow())\n```\n\n**Performance**: Validation + Submission happens in parallel = **Super fast** ⚡⚡⚡\n\n---\n\n## 5.
